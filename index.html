1. Abstract

2. Technical Formalization of the Classical Baseline

In classical architectures (e.g., InceptionResNetV2 + GRU + Soft Attention), an input image $I \in \mathbb{R}^{H \times W \times C}$ is converted by encoder $f_{\theta}$ into spatial feature map $V$:

$$V = f_{\theta}(I) \in \mathbb{R}^{h \times w \times d_v} \implies N = h \cdot w = 64 \text{ region vectors } (d_v=1536)$$

At decoding step $t$, the GRU updates hidden state $h_t = \operatorname{GRU}(x_{t-1}, h_{t-1})$. Soft cross-attention weights spatial region features $v_i$ against Query $h_t$:

$$\alpha_{t,i} = \frac{\exp(e_{t,i})}{\sum_{j=1}^N \exp(e_{t,j})}, \quad e_{t,i} = w_a^\top \tanh(W_q h_t + W_k v_i), \quad c_t = \sum_{i=1}^N \alpha_{t,i} v_i$$

3. The Generative Caption Enrichment (GCE) Dilemma

Caption detail and factual support are separate properties and should be measured separately. This repository does not reproduce a comparison of synthetic and human-annotated training data, and its current object-list evaluator is only CHAIR-inspired. Any claim about hallucination rates or the effect of fine-tuning requires a defined dataset, annotations, and reproducible runs.

Evaluation Metrics & The GCE Dilemma

Reference-based metrics

BLEU-4 and ROUGE-L

Implemented in caption_metrics.py for one reference and one generated caption. NLTK and rouge-score must be installed.

Object hallucination

CHAIR-inspired check

Compares COCO-name mentions in a caption with supplied object labels. This is not validated canonical CHAIR and needs ground truth.

Not implemented here

CIDEr, SPICE, CLIPScore, region metrics

No calculation or browser endpoint for these metrics is present. Detection boxes are not compared with masks or caption phrases.

The live caption endpoint does not run caption metrics or CHAIR evaluation. Dataset evaluation is a Python utility described in the documentation.
