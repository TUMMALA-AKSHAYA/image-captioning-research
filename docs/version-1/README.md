# CaptionLens — Documentation Version 1

This folder contains the first organized snapshot of the CaptionLens image-captioning research materials.

## Contents

- `research/` — updated research review and requirements coverage
- `presentation/` — professor discussion PowerPoint
- `literature/` — year-wise paper table, literature workbook, and IITH research supplement
- `audit/` — claim verification, search log, change log, and completion/limitations report

## Research status

This is a scoped, evidence-backed research update, not an exhaustive systematic review. Some paper metadata, dataset splits, and results remain marked as pending verification. No new CaptionLens experiments are claimed as completed. See the research review and completion report for limitations.

## Versioning

This is the initial documentation snapshot (`version-1`). Preserve this folder as a historical record; create a new `version-2` folder for substantial future revisions if you want versioned snapshots.
